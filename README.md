# Bank Transaction Demo Simulator

GitHub Pages-ready front-end simulator.

Features:
- Bank selector with different demo themes
- Transaction/UPI/IMPS references
- Amount, date, time, beneficiary, account and IFSC fields
- Optional user-provided logo upload
- Demo receipt preview
- PNG download and print
- Prominent DEMO / NOT A REAL TRANSACTION disclosure

This is not connected to a bank, UPI, IMPS, NEFT or payment processor and is not designed to create authentic payment proof.
